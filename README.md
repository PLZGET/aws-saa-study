# SAA Study OS — Green UI

기존 SAA Study OS v3의 UI 스타일만 변경한 버전입니다. 네이버 포털의 녹색 포인트, 밝은 바탕, 단정한 카드 및 탐색 메뉴에서 착안한 디자인을 적용했습니다. 네이버 공식 서비스가 아니며 네이버 상표와 로고는 사용하지 않습니다.

## 실행 방법

- 단일 파일: `SAA_Study_OS_Green.html`을 브라우저에서 열기
- 프로젝트: `index.html`을 브라우저에서 열거나 정적 웹 서버에서 호스팅

## 유지된 기능

- SET 1~5(각 50문제), PDF 163문제 원문 및 해설, 65문제/130분 모의고사
- 오답노트, 북마크, 통계, 학습 메모, JSON 및 CSV 백업, GitHub 문제은행 동기화
- 기존 `localStorage` 키와 모든 자바스크립트 로직 완전 동일. 동일한 브라우저와 오리진에서 실행 시 학습 기록을 이어 사용할 수 있습니다. 파일 경로나 호스트가 바뀌면 기존 기록이 자동으로 보이지 않을 수 있으므로 JSON 백업/복원을 권장합니다.

## 수정 범위

- `<style>`에 `naver_ui_override.css` 내용을 추가하고 테마 색상/문서 제목만 조정했습니다.
- 문제 데이터, JSON, PDF 원본, 이벤트 핸들러, 채점 및 저장 로직은 수정하지 않았습니다.
- 최초 SET 2~5 인터넷 동기화 요구 및 원본 라이선스 고지는 기존과 동일합니다.
